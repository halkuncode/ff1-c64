What is done:
  When a spell is being purchased
  the code compares "Spell BITS" to a value
  from a bit test table. [ $08, $40, $20, $10, $08, $04, $02, $01 ]
  Each bit represents a spell. If the BIT in "Spell BITS" is SET
  Then that spell CAN NOT be learned!
