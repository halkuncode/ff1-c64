_____________________________________________________-Overview-__________________________________________________________
_________________________________________________________________________________________________________________________



..........Everything can be edited with Hackster, but there are a few things to be aware of. Because of the added enemies
..........in GFF, there is a problem that occurs if you save in the Battle Editor after just visiting Battles 77-7a.

..........Hackster follows an enemy list from Goblin (00) up to Chaos (7f), but those particular enemies are 81/82/83/84.
..........What will happen is, if you go to one of those 4 battle formations, Hackster will acknowledge that as a visited
..........formation. If you go to another formation (without exiting out of the Battle Editor altogether) and save,  ..........it will save over formations 77-7A if you visited them.

..........After you are done making any changes while using the Battle Editor, fix these addresses if they get changed.

..........2cb82:81.....2cb92:82.....2cba2:83.....2cbb2:84

..........You can place enemies 80, 81, 82, 83, and 84 in any formation you like, manually with a Hex Editor.
..........Make sure to check and fix those formations manually with a Hex Editor. 
..........If they are visited in the Battle Editor, and you make changes elsewhere, and save, they will need to be fixed.
..........Enemy # 80 is Bahamut, and wont have the intended graphics, if you place him in a Formation.


..........Battle Formations that appear in oceans and rivers is done in the Standard Map Editor.

..........Coneria: Northern Rivers
..........Provoka: Southern Rivers
..........Elfland: Ocean


..........Battle backdrop Palettes are done in the Overworld Map section of Hackster.


..........The byte value for each Enemy is provided. It is nearly impossible to read any text in GFF when (View with DTE)
..........is off. You can just as easily select the enemies with a Hex Editor, under 02-05. E1, E2, E3, and E4.
